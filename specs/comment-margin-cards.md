# 批注页边对话卡

> 2026-10-24 作者确认方向：批注对话从侧栏搬到正文旁边，不用再在侧栏和原文之间来回对照。
> 和 §5.3「编辑器里不加跟随文字的浮层」不冲突：被否掉的是按坐标追着选区重新定位的浮层（会跳），
> 页边卡是正文滚动内容的一部分，和文字一起滚，本身不重新定位。

## 做什么

### 页边在哪

- 编辑器（实时预览 / 源码模式）正文右侧一条页边，宽约 280px，每条批注一张卡。
- 卡片在正文的滚动内容里，**和正文一起滚**；卡片顶端对齐它圈住的文字所在的那一行。
- 几条批注挨得近时依次往下错开，不重叠；展开的那张优先对齐原文，其他卡片让开。
- 本文**有批注**（或正在新建第一条）时，正文版心往左让出页边；没有批注的文档版面不变。
- 页边放不下（窗口太窄、两侧栏都开着，可用宽度不到一张卡）时不显示页边，退回现在的侧栏详情页，功能不少。

### 卡片

- **收起**（默认）：`#编号`、「等你 / 等 Agent」、最后一条消息的前一两行。「等你」的卡片用强调色区分。
  原文已删除 / 无法定位的，卡片上带同样的小标记（无法定位的卡片没有行可对齐，排在页边最下面）。
- **展开**：同一时间只展开一张。内容就是现在侧栏详情页的全部：原文引用、完整对话、修改建议和「采纳」、
  多行回复框（回车换行，按钮发送）、「已解决 / 不采纳 / 编辑 / 重新绑定」。
  对话里的文字可以选中复制，点了不跳转。
- 回复框的草稿在收起 / 切走后保留（沿用现在按文档 + 批注号保存的做法），发送成功后才清掉。
- Agent 改了批注文件 → 卡片原地刷新，展开状态、正在写的回复和输入焦点不丢。

### 怎么打开、怎么关

- 点正文里的批注标记 / 脚注号 → 展开对应的页边卡（不再把侧栏切到详情页）。
- 点卡片 → 展开，同时正文里那段批注标记加深显示（不移动光标、不选中文字，免得打断写作）。
- 按 Esc、或点回正文 → 收起。
- 新建批注：选中文字 →「添加批注」→ 页边直接出一张空白的展开卡写第一条消息，不再弹屏幕居中的输入框。
  页边放不下时仍用居中输入框。

### 侧栏「批注」标签

- 留作全篇总览：「等你 / 等 Agent / 全部」标签、列表、「复制批注指令 / 复制回复指令」都不变。
- 点列表一行 → 正文滚到那处并展开页边卡；侧栏留在列表页。
- 详情页只在页边放不下时使用。

### 和其他模式

- 沉浸模式、番茄钟锁定中：页边卡全部收起，不自动展开，可以手动点开。
- 打字机模式：卡片跟着正文一起滚，不另做处理。
- 只在桌面端，和现在一样。

## 不做什么

- 不改批注文件格式、定位算法、正文零污染、`data.json` 结构；不加设置项、不注册命令。
- 不做阅读视图里的页边卡（阅读视图本来就没有批注标记）。
- 不做手机端。
- 不做段落下方展开的形式。
- 不做「插件替作者调用 Agent」（2026-10-24 讨论后放弃，理由见下一节）。

## 附：每轮在同一个对话里接着聊（2026-10-24 作者确认，已先于页边卡实现）

讨论过「插件替作者调用 Agent」（自带 ACP / 模型 API 通道，或交给 Qiaomu Agent 代发），都放弃了：
每轮新开对话，Agent 要重读记忆、正文和规矩，费 token，也丢了上一轮聊出来的默契。
作者更想在本机 Agent 的**同一个对话**里一直聊，插件只把「每轮提醒一下」变轻。

### 做什么

- 「复制回复指令」变短：只点明是哪几条（`#2、#5`）、请 Agent 只读这几条，不再整段重复读稿邀请和规矩；提示语改成「发到和它聊批注的那个对话里」。
- `list_comments` 新增可选参数 `only_your_turn`：只返回轮到 Agent 的批注，不把聊过的整串对话再读一遍。
- 「复制批注指令」（工具通道）末尾先说好以后怎么接着聊：作者会在这个对话里说一声或敲 `/pizhu`，到时只看轮到你的。
- 设置 → 批注 → Agent 连接卡新增「每轮的快捷命令」：
  - Claude Code / Gemini CLI：复制一条终端命令，把 `/pizhu` 写进 `~/.claude/commands/pizhu.md` / `~/.gemini/commands/pizhu.toml`（用户级，运行一次）；
  - 其他 Agent：复制那段话，存成自己的快捷短语。
  - 跟着上面「连接到 Agent」选的 Agent 走；插件不替用户写库外文件。

### 不做什么

- 不由插件发起 Agent、不接 Qiaomu Agent、不做 ACP / API 通道。
- 不加 `data.json` 字段、不注册命令。
- 「等作者」长轮询工具（Agent 挂着等作者点按钮）先不做。
