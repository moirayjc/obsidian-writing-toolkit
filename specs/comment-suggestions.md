# 批注：Agent 只提「修改建议」+ 专用批注工具（MCP）

> 2026-10-23 作者确认。接在 [`comment-threads.md`](comment-threads.md) 之后。
> **2026-10-27 作者决定撤回第二、三节（专用批注工具 / MCP、连接到不同的 Agent）**：门槛太高，普通用户看不懂。
> Agent 一律直接读写批注文件；第一节「修改建议」和「每轮的快捷命令（/pizhu）」保留（/pizhu 改为读写文件）。
> 目的：把批注做得更像 Word 的「批注 + 修订」——
> 1. Agent 不直接改正文，只提「把 A 改成 B」，由作者点「采纳」，插件在编辑器里替换；
> 2. Agent 不直接写批注文件，而是通过插件提供的专用工具发起 / 回复，工具当场校验，且根本没有结案的操作。
> 这样「只有作者能结案」「正文只有作者能改」都由结构保证，不再靠说明里的规矩；正文只在 Obsidian 编辑器里被改，现有的位置跟踪一直有效。
> 标【建议】的是我替作者做的取舍，不同意直接改。

## 做什么

### 一、修改建议（Word 的「修订」）

- Agent 的一条消息可以附带一个修改建议：「把正文里的 A 改成 B」。
  - A 默认是这条批注现在圈住的文字；也可以是同一段里更长的一段（比如整句、整段），但必须在当前正文里**逐字存在且只出现一次**。
  - 批注文件里的写法（Agent 消息下面紧跟两行）：

    ```
    - Agent：「提溜」太口语，换个利落点的动作。
    - 建议原句：直接把人从地上提溜了起来
    - 建议改为：一把将人从地上拎了起来
    ```

  - 采纳后，「建议改为」那一行变成 `- 建议改为（已采纳）：……`，留着给 Agent 下一轮看。
- 详情页里，带建议的 Agent 消息下方显示一个差异块：删掉的字划线、新增的字高亮（沿用快照对比的字级差异样式），下面两个按钮「采纳」「复制」。
  - **只有这条批注里最新的一条建议能采纳**；更早的建议显示为灰色「已被新建议取代」，仍可复制。
- 点「采纳」：
  - 文档没打开就先打开并跳到那处；
  - 插件在编辑器里把 A 替换成 B（作为作者的一次输入，⌘Z 能撤销），批注的标记跟到新文字上，「现文」随之更新；
  - 批注**不会自动结案**，卡片显示「已采纳 · 满意就点『已解决』」。不满意可以继续回复，让 Agent 再出一版。
- 采纳不了的情况，按钮变灰并说明原因，不报错、不乱改：
  - 作者在 Agent 提建议之后又改过这处，A 在正文里找不到了 →「这处已经改过，建议过期了」，可以复制建议手动参考；
  - A 在正文里出现了不止一次 →「正文里有多处相同的文字，无法确定改哪一处」；
  - 本章已定稿锁定 → 沿用定稿锁的提示。
- 【建议】**作者说「改」以后由 Agent 直接改正文**这条规则作废：讨论中、定稿时，Agent 都只提建议，正文一律由作者采纳。
  作者想让 Agent 大段重写一整场戏，那是批注之外的正常改稿，不归这套流程管。
- Agent 发起新批注时也可以直接附建议（错别字、病句这类，作者一眼看完点采纳就行）。

### 二、专用批注工具（插件在本机提供 MCP）

- 【建议】做成 **MCP**，由插件在本机开一个只供本机访问的服务，不做独立的命令行脚本。理由：
  - 插件发布出去只有 `main.js` 等三个文件，带不了额外的脚本；
  - Claude Code、Codex 等主流 agent 都能接 MCP，作者自己的流程（Obsidian 开着、agent 在旁边跑）正好满足；
  - 插件是批注文件唯一的写入方，读到的是编辑器里最新的正文（包括还没保存的），校验最准。
- 设置 → 写作 → 新增「允许 Agent 通过批注工具连接（仅本机）」，**默认关**，只在桌面端出现。
  - 打开后显示端口和一个「复制连接命令」按钮（比如 `claude mcp add --transport http 写作工具箱 http://127.0.0.1:<端口>/mcp --header "Authorization: Bearer <口令>"`），作者粘到 agent 那边配一次即可。
  - 只监听 `127.0.0.1`，没带口令或口令不对的请求一律拒绝，带浏览器来源头的请求也拒绝（防止网页偷偷调用）。
  - 端口被占用时提示换一个端口，不静默失败。
  - 口令每台电脑各自生成，【建议】存在本机，不放 `data.json`（`data.json` 会被同步覆盖，见设计文档 §5.2 第 58 条）。
- 工具只有这几个，**没有结案、否决、删除、改正文、改别人消息的工具**：

  | 工具 | 做什么 | 当场拒绝的情况（把原因返回给 Agent，让它重来） |
  |---|---|---|
  | 列出批注 | 给定文档（或不给 = 所有有批注的文档），返回每条的编号、原文 / 现文、所在段落、完整对话、轮到谁、最新建议的状态，以及「已否决」列表 | 文档不存在 |
  | 发起批注 | 给文档、要圈住的文字、意见，可选附建议 | 文字在当前正文里找不到；出现不止一次（提示「加长一点再试」）；和进行中的某条批注圈住的位置重叠（提示「请回复第 N 条」）；建议原句不合格（同上一节的要求） |
  | 回复批注 | 给文档、编号、内容，可选附建议 | 编号不存在；这条现在不是轮到 Agent（最后一条是 Agent 的）；建议原句不合格 |

  - 【建议】「回复」限制为只能回轮到自己的批注，防止 Agent 在作者没回话时自己连发。
  - 「发起」碰到和「已否决」里意见相近的，工具不拦（判断不了「相近」），靠给 Agent 的说明约束。
  - 通过工具写入时，批注文件由插件按现有格式写，「位置 / 段落 / 创建」都由插件填，不用 Agent 自己写。
- 「复制批注指令」「复制回复指令」随开关变化：
  - 开关打开时：指令改成「用写作工具箱的批注工具……」，并写明「没有这个工具就停下来告诉我，不要直接改批注文件，也不要改正文」；
  - 开关关着时（没有 MCP 的 agent、手机）：沿用现在直接写批注文件的指令，只把「作者说改就改正文」换成「写『建议原句 / 建议改为』两行」，现有的越权提醒照常兜底。
- 批注文件开头给 Agent 看的说明同步改：不改正文、改动用建议两行写、不改「现文」（「现文」从此只由插件写）。

### 三、连接到不同的 Agent（2026-10-23 作者确认）

- 设置页的「复制连接命令」改成「连接到 Agent」：下拉框选 Claude Code / Gemini CLI / Antigravity / 通用（地址 + 口令），再点「复制」。
  - Claude Code：`claude mcp add --scope user --transport http …`；
  - Gemini CLI：`gemini mcp add --scope user --transport http --header "Authorization: Bearer <口令>" writing-toolkit <地址>`；
  - Antigravity：复制 `mcpServers` 里的一项 `"writing-toolkit": { "serverUrl": …, "headers": { "Authorization": … } }`（字段是 `serverUrl`，不是 `httpUrl`），提示粘进 `~/.gemini/config/mcp_config.json`、保存后重启；
  - 通用：只复制地址、传输方式和请求头。
- 下拉框记住上次选的，和开关 / 端口 / 口令一样只存在这台电脑上。
- 插件不替作者改 `~/.gemini/` 下的配置文件（库外别的程序的配置）；批注工具与给 Agent 的指令不分是哪家。

### 四、给 Agent 的指令要有温度（2026-10-23 作者试用后确认）

- 试用发现：指令里规矩太多、又把建议写得很显眼，Agent 只剩客观、机械的挑错，没有以前灵动。作者要的是有温度的共创者，聊天框要像在聊天。
- 两份指令（工具 / 文件两种通道）都改成：先邀请 Agent 像读进去了的朋友、懂行的编辑那样说真实感受（打动、出戏、人物、好奇、不同意，可以提问、夸、争），用自己的语气；修改建议明说是可选的；批注留完后回到对话里聊整篇感觉和最想讨论的一两件事。回复指令鼓励讲理由、反问，可以另开新批注。
- 格式规矩压成最后括号里的一段；硬约束靠工具当场校验（工具通道）或批注文件抬头（文件通道）。工具说明、MCP 服务说明、批注文件抬头的语气同步放软，硬约束不变。

## 不做什么

- 不在编辑器正文里直接显示修订痕迹（划线 + 插入的那种行内样式）；建议只在侧栏详情页里显示。行内显示要处理光标、输入法和滚动，历史上浮层就吃过亏，以后再说。
- 不做「全部采纳」「批量采纳」。
- 不做在回复框里直接叫 agent（插件不调用 agent），每一轮仍由作者在 agent 那边发起。
- 不把位置标记写进正文，保持正文零污染。
- 不改批注文件位置、已有字段、定位算法、标签 → 列表 → 详情的面板结构。
- 不提供命令面板命令（四个入口的硬约束不变）。
- 不做移动端的批注工具服务（手机上没法开本机服务）；手机上如果开着批注，能看到建议、也能点采纳。
- 不处理批注文件随文档改名搬家的问题（现有行为不变）。
