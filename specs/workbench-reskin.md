# 编辑台换肤（书目风）

设计稿：测试库 `.wt-preview/wb-redesign/mock.html`（出图 `mock.png`：A 暖纸浅 / B 暖纸深 / C 搜索态）。
设计稿只用现有 `--wt-*` 令牌与真实取值，不引入新颜色。

## 做什么

**书头**
- 书名改宋体（`--wt-serif`）20px，去掉书名下划线。
- 连载状态从「无字小圆点」改成**带字小胶囊**（连载中 / 已完结 / 暂停 / 未标注），点击行为不变（同一菜单）。
- 「1.2 万字 · 38 章」：数字用 `--wt-num` 放大一档，单位缩小变淡，中间细竖线分隔。
- 正文 / 设定：凹槽轨道 + 选中项浮起白卡（`--wt-paper-2` 槽 + `--wt-card-bg` 卡 + `--wt-shadow-card`），计数改成同行淡色数字。
- 「+ 新章节」改用 `--wt-accent` 实心（浅色朱砂 / 深色珊瑚），「新卷」改为幽灵按钮放在它左边。
- 右上三个图标按钮统一 28px 幽灵形态；搜索展开时搜索按钮呈激活态。

**台面**
- 卷头：宋体卷名；去掉整条青色下划线，卷进度改为卷头右端 28px 迷你进度条（写满 = `--wt-jade`，未满 = `--wt-ink-3`）；元信息「12/12 · 3,861 字」。
- 卷内左侧一根 0.5px 细竖线做书目骨架。
- 章节行 32px：章号（`--wt-num` 等宽）· 标题 · 定稿锁 · 字数。
- **去掉每行的状态圆点**：已写与否改由字数列表达——空章显示淡色「未写」、标题变淡。
- 当前章：浮起白卡 + 左侧骨架线上一段 2px 朱砂书签；章号与标题朱砂加粗。
- 悬停 = `--wt-wash` 底；键盘焦点 = 1px 朱砂细环；拖拽落点卷 = 朱砂淡底 + 细环；被拖章节半透明。
- 搜索：输入框聚焦环、「第 N / 共 M 处 · K 章」+ 上下箭头；命中片段里关键字用朱砂淡底标出；命中数为小胶囊。
- 「正在编辑另一本书」提示条改为琥珀淡底卡片，「切换过去」为白色小按钮。

**今日（底部）**
- 第一行「今日 1,286 / 2,000 字 …… 64%」（达标时右侧显示「达标」、进度条变 jade）。
- 4px 圆角进度条。
- 番茄 / 码字时长 / 时速改为带小图标的芯片，一行排完；点击行为不变。

**通用**：暗色、冷淡、高对比三套主题全部走令牌自动适配；高对比度保持平铺（不加投影，沿用 `--wt-shadow*: none`）；`body.wt-mobile` 下 FAB / 行高按手机触控尺寸检查。

## 不做什么

- 不改任何功能、入口、菜单项、快捷键、拖拽规则、数据结构与设置项；不新增命令。
- 不重写 `styles.css`：只在「编辑台」分区内改 / 追加，按 `wt-wb-*` 现有类名落地。
- 设定（资料）列表只跟随章节行的同一套行样式，不单独设计。
- 不动工具箱、主页、设置页。
