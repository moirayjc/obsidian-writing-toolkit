# 伴随数据存放位置 + 批注在移动端可选

> 2026-10-23 作者确认。
> 背景：Obsidian 官方同步（Obsidian Sync）不同步以 `.` 开头的目录（`.obsidian` 除外，官方无开关）。
> 本插件的批注 `.wt-comments/`、快照 `.wt-snapshots/`、章纲 `.wt-outlines/` 都在隐藏目录里，
> 用官方同步的用户这三样**到不了第二台设备，且没有任何提示**。发布给别人用之前必须给出可同步的选项。
> 同时，「移动端不提供批注」是按作者自己的同步方案定的，对别的用户应当是可选项。
>
> 每条后面的【建议】是起草时的倾向，作者确认时可逐条改。

## 做什么

### 一、伴随数据存放位置（新设置项）

- 设置页「写作」下新增一项「伴随数据存放位置」，两档：
  - **隐藏目录（默认）**：`.wt-comments/`、`.wt-snapshots/`、`.wt-outlines/`，与现在完全一致，老用户无感。
  - **可同步目录**：库根下 `_写作工具箱/批注/`、`_写作工具箱/快照/`、`_写作工具箱/章纲/`，各自仍按正文路径镜像。
  - 设置说明写明：「用 Obsidian 官方同步的请选『可同步目录』，否则批注、快照、章纲不会同步到其他设备。iCloud、坚果云、Git 等通常两种都能同步。」
  - 【建议】目录名用 `_写作工具箱`：下划线开头在文件列表里排最前、一眼看出不是正文；中文与插件其余命名一致。
- **切换即迁移**：改这一项时弹一次确认（写明会搬多少个文件），确认后把三类数据整体搬到新位置；目标处已有同名文件的跳过并在结束时列出，不覆盖。可以随时切回去（同样迁移）。迁移中途失败的那一个保持原样，读取时新旧两处都认，数据不丢（沿用批注从同目录迁到 `.wt-comments/` 那套兜底）。
- **可见目录必须接进排除体系**：`_写作工具箱/` 下的文件在每一处「这算不算正文 / 章节」的判断里都排除——作品识别、章节列表、字数统计、编辑台搜索、快照自身、主页与编辑台列表等（对照设计文档「把伴随文件接进排除体系」那份清单逐处核对）。
- **Obsidian 自己的搜索 / 关系图 / 快速切换**会看到这些 md 文件（插件管不到）。设置项下给一个按钮「加入 Obsidian 的排除列表」，点了把 `_写作工具箱/` 加进「设置 → 文件与链接 → 排除的文件」。
  【建议】做成按钮而不是自动写入：那是用户自己的 Obsidian 配置，不该悄悄改。
- **快照已有的「快照文件夹」设置**：保留并继续生效，但只在用户改过（不是默认 `.wt-snapshots`）时显示为「高级：自定义快照文件夹（优先于上面的存放位置）」。没改过的用户只看到统一的一项。
  【建议】不自动迁移改过快照文件夹的老用户：他们是主动选的位置（设置说明里原本就写着「要用坚果云同步就改成普通文件夹名」）。
- **章纲的「写进 frontmatter」模式**不受影响（那种模式本来就随正文同步）。
- **存放位置以库里的实际数据为准（2026-10-23 修订，作者确认）**：
  - 原方案把档位只存在本机 `data.json`、另一台设备有数据时提示切换。工作库实测：作者用 Remotely Save 且同步配置目录，手机和电脑的 `data.json` 每 5 分钟互相覆盖（保留较新），手机上的旧值把电脑的「可同步目录」改回了「隐藏目录」，连「不再提示」也被清掉。档位放在 `data.json` 本身就错了（设计文档 §5.2 第 58 条：要跨设备一致的状态别放 `data.json`）。
  - 现在：启动时看两处有没有**真实文件**（空文件夹、`.DS_Store` 这类系统垃圾不算）：只有可同步目录有 → 用可同步目录；只有隐藏目录有 → 用隐藏目录；都没有 → 沿用 `data.json` 里记的（只当缓存）。不搬任何文件，只决定读写哪里。
  - 两处都有真实文件（比如两台设备各自写过）：沿用 `data.json` 里记的，并提示一次，给「合并到可同步目录」「合并到隐藏目录」（合并 = 把另一处的文件搬过来，同名跳过不覆盖）和「不再提示」。
- **搬完清理**：确认旧位置里已经没有任何真实文件后整棵删掉（不逐层删）；删不掉时在控制台留下具体错误。工作库实测：逐层删在真机上失败，留下一整棵空文件夹。
- 给 Agent 的批注指令与批注文件抬头里的路径，跟着当前位置走（现在已是按 `sidecarPathFor` 生成，确认改位置后仍正确）。

### 二、批注在移动端可选（新设置项）

- 设置页「批注」下新增「在手机和平板上使用批注」，**默认开**。关掉时行为与现在一致：移动端没有批注页、工具条按钮、长按入口和正文痕迹。
- 作者自己的库：装上新版后需要在手机上把它关掉一次（每台设备的设置各自独立）。
  【建议】不为作者特判默认值：插件发布后默认值应当对新用户合理。

### 三、README 说明设备差异

- 写明：平板使用桌面布局；番茄钟锁定只在桌面端；读者手机预览与计划看板目前只在桌面端（平板待验证）；批注、快照、章纲在官方同步下需要选「可同步目录」。

## 不做什么

- 不检测用户是否开了 Obsidian 官方同步（要用未公开接口，版本升级可能失效）；只在设置说明里讲清楚。
- 不把计划看板、读者手机预览放开到平板（作者没有平板，验证不了；等有反馈再做）。
- 不改其余按设备区分的行为（抽屉、长按、手机布局、番茄钟锁定、打开系统文件夹、剪贴板写法）。
- 不改批注 / 快照 / 章纲的文件格式，不改 `data.json` 已有字段的含义。
- 不做「存放位置」以外的自定义路径（只两档 + 快照老设置兼容）。
- 不注册命令。
